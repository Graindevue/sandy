# PROCESS

Process the branches **one at a time, in the order listed**. For each branch:

1. `git merge <branch> --no-edit`.
2. If there are merge conflicts, resolve them by reading both sides and choosing
   the correct combined result. Never blindly take one side.
3. Verify the integration branch is still green:
   - `pnpm type-check`
   - `pnpm test`
   - `pnpm lint` (run `pnpm lint:fix` to auto-fix formatting in touched files)
4. If verification fails, first try to fix it with a **minimal** follow-up commit
   (the failure is usually a small integration mismatch between two branches).
5. If you cannot get the integration branch green for this branch within a couple
   of attempts, **abort that branch and skip it**:
   - `git merge --abort` (or `git reset --hard HEAD` if the merge already
     committed) to return the integration branch to its last green state.
   - Record the branch as skipped with a one-line reason.
   - Continue with the next branch — one bad branch must NEVER block the others
     and must NEVER leave the integration branch broken.

# RULES

- The integration branch must be green after every branch you keep. When in
  doubt, skip rather than ship a broken merge.
- Resolve conflicts to preserve the intent of BOTH branches.
- Commit messages: Conventional Commits, no AI co-author / "generated by"
  footers (see `AGENTS.md`).
- Do **not** run `pnpm -r build` — Convex codegen needs a live deployment and
  will fail here. `pnpm type-check` / `pnpm test` / `pnpm lint` are the gate.
- Do **not** `git push`. Do **not** `gh issue close`. The orchestrator pushes
  the integration branch and closes the merged issues after this run returns.

# OUTPUT

After processing every branch, output exactly one `<merge-result>` block listing
which issues were merged (kept) and which were skipped. Use the issue **id**
(the number), not the branch name:

```text
<merge-result>
{"merged": ["42", "43"], "skipped": [{"id": "44", "reason": "test failures after merge could not be resolved"}]}
</merge-result>
```

If nothing could be merged, output `{"merged": [], "skipped": [...]}`.
